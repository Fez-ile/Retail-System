## Image Replacement Process

### When You Have Your Images Ready:

1. **Prepare Images**
   - Resize to correct dimensions
   - Compress with TinyPNG or ImageOptim
   - Save as JPG (recommended) or PNG

2. **Rename Files** (EXACT names required)
   ```
   essentials.jpg
   seasonal.jpg
   capsule.jpg
   campaign.jpg
   about-hero.jpg
   ```

3. **Upload to Server**
   - Navigate to: `c:\xampp\htdocs\Retail system\assets\images\`
   - Copy/paste images into this folder
   - (Folder already exists and is ready)

4. **Verify Display**
   - Open website in browser
   - Refresh page (Ctrl+F5)
   - Check homepage for featured images
   - Check campaign section
   - Check About page hero
