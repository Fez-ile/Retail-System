## ⚙️ How Image Loading Works

1. **Browser requests page** (e.g., index.php)
2. **PHP file loads** with image tags
3. **HTML renders** with `<img src="assets/images/essentials.jpg">`
4. **Browser sees src attribute**
5. **Makes request** to assets/images/essentials.jpg
6. **Server finds file** (if it exists)
7. **Image displays** in browser ✅

## 🔧 Troubleshooting Guide

### Issue: Images Not Loading
```
Check: Filename spelling (case-sensitive)
Check: File location (assets/images/ folder)
Check: File exists on server
Fix: Clear browser cache (Ctrl+Shift+Del)
Fix: Refresh page (Ctrl+F5)
```

### Issue: Images Look Blurry
```
Cause: Low resolution source
Fix: Use higher resolution image
Fix: Don't enlarge past original size
Fix: Re-compress carefully
```

### Issue: Page Loads Slowly
```
Cause: Large image files
Fix: Compress more (TinyPNG.com)
Fix: Reduce dimensions
Fix: Use JPG instead of PNG
```
