## 🔑 KEY FILE NAMES

**MUST BE EXACT** (case-sensitive, lowercase):

```
✓ essentials.jpg
✓ seasonal.jpg
✓ capsule.jpg
✓ campaign.jpg
✓ about-hero.jpg
```

**Not these:**
```
✗ Essentials.jpg (capital E)
✗ seasonal.JPG (capital JPG)
✗ capsule.png (wrong extension)
✗ campaign_large.jpg (wrong name)
✗ about_hero.jpg (underscore, not hyphen)
```

## 💡 PRO TIPS

1. **Read QUICK_REFERENCE.txt first** - Gets you oriented in 2 minutes

3. **Use VERIFICATION_CHECKLIST.txt** - Test each section systematically

5. **Clear cache before testing** - Ctrl+Shift+Delete then Ctrl+F5

6. **Test on mobile** - Responsive design critical for luxury brand

7. **Compress images** - Use TinyPNG.com (free)

8. **Use JPG format** - Better compression than PNG

9. **Get filenames EXACT** - Case-sensitive, lowercase

10. **Upload to assets/images/** - Not root folder
