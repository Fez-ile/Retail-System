## Image Optimization Tips

### Before Uploading:

1. **Check Dimensions**
   - Featured cards: Square (400x400 minimum)
   - Campaign: 500x600 pixels
   - About hero: 1200x800 pixels

2. **Compress Images**
   - Use **TinyPNG.com** (recommend this)
   - Or **JPEGmini.com**
   - Goal: Keep under 150 KB per image

3. **Save as JPG**
   - Better compression than PNG for photos
   - Smaller file sizes = faster loading

4. **Match Brand Aesthetic**
   - Use minimal, clean images
   - Black, white, beige, grey tones
   - Professional and elegant look

## Filename Reference

**IMPORTANT**: Filenames must be EXACT and lowercase with .jpg extension:

```
✓ CORRECT:
  - essentials.jpg
  - seasonal.jpg
  - capsule.jpg
  - campaign.jpg
  - about-hero.jpg

✗ WRONG (won't work):
  - Essentials.jpg (capital E)
  - seasonal.JPG (capital JPG)
  - CAPSULE.jpg (all caps)
  - campaign.png (wrong extension)
  - abouthero.jpg (missing hyphen)
```

## Troubleshooting

### Q: Images not showing?
**A:** 
- Check filename spelling exactly
- Verify files are in `assets/images/` folder
- Clear browser cache (Ctrl+Shift+Delete)
- Refresh page (Ctrl+F5)

### Q: Images look blurry?
**A:**
- Use higher resolution source
- Check original image quality
- Try re-saving at higher quality

### Q: Page loads slow?
**A:**
- Compress images more (TinyPNG)
- Reduce file size under 150 KB each
- Use JPG instead of PNG

### Q: Can't find assets/images folder?
**A:**
- Navigate to: `C:\xampp\htdocs\Retail system\`
- Look for `assets` folder
- Inside should be `images` folder
- If doesn't exist, create it manually
