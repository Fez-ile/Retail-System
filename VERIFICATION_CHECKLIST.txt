## 🔧 Troubleshooting Checklist

If images don't appear, work through this:

### Images Show as Broken Links
- [ ] Clear cache and refresh (Ctrl+Shift+Delete, then Ctrl+F5)
- [ ] Check filenames for typos
  - [ ] Verify: **essentials.jpg** (not Essentials.jpg)
  - [ ] Verify: **seasonal.jpg** (not seasonal.JPG)
  - [ ] Verify: **capsule.jpg** (not capsule.png)
  - [ ] Verify: **campaign.jpg** (not campaign_image.jpg)
  - [ ] Verify: **about-hero.jpg** (not about_hero.jpg)
- [ ] Check files are in correct folder
  - [ ] Navigate to: `c:\xampp\htdocs\Retail system\assets\images\`
  - [ ] All 5 files present
- [ ] Check file permissions
  - [ ] Right-click on file → Properties
  - [ ] Ensure "Read" permission enabled
- [ ] Restart Apache server
  - [ ] Stop XAMPP
  - [ ] Start XAMPP
  - [ ] Test again

### Images Look Blurry or Pixelated
- [ ] Check original image resolution
  - [ ] Was it high enough?
  - [ ] Don't enlarge past original size
- [ ] Consider using different source image
  - [ ] Download higher quality version
  - [ ] Or take new photo with better camera
- [ ] Re-compress with TinyPNG
  - [ ] Make sure compression wasn't too aggressive

### Page Loads Slowly
- [ ] Check file sizes
  - [ ] Each file should be 50-300 KB
  - [ ] Total should be under 1 MB
- [ ] Re-compress with TinyPNG more aggressively
- [ ] Consider reducing image dimensions
- [ ] Use JPG instead of PNG format

### Text Not Visible Over About Hero Image
- [ ] Image opacity might be too high
  - [ ] Should be 70% (0.7) in CSS
  - [ ] Check: `.about-hero-image { opacity: 0.7; }`
- [ ] Try with a different background image
  - [ ] Maybe too dark for white text
  - [ ] Use lighter image or different content
