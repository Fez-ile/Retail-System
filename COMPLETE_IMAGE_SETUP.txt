## 📱 Responsive Behavior

Your images will automatically adjust on different screen sizes:

### Desktop (1400px+)
- Featured: 3 columns side-by-side
- Campaign: 2 columns (image + text)
- About hero: Full width

### Tablet (1024px)
- Featured: Still 3 columns (slightly smaller)
- Campaign: 2 columns (adjusted spacing)
- About hero: Full width

### Mobile (768px+)
- Featured: 2 columns (wraps to rows)
- Campaign: Stacked (image on top, text below)
- About hero: Full width

### Small Mobile (480px+)
- Featured: 1 column (all stacked)
- Campaign: Stacked vertically
- About hero: Full width

All images maintain aspect ratios and look professional at any size! ✨

## 🐛 Troubleshooting

### Problem: Images not showing
**Solution:**
1. Check filenames are EXACT (case-sensitive)
2. Verify files are in `assets/images/` folder
3. Clear browser cache: Ctrl+Shift+Delete
4. Refresh page: Ctrl+F5
5. Check file permissions

### Problem: Images look blurry
**Solution:**
1. Use higher resolution source image
2. Don't scale up past original size
3. Ensure image isn't corrupted
4. Re-compress carefully

### Problem: Page loads slowly
**Solution:**
1. Compress images more (TinyPNG)
2. Reduce dimensions if oversized
3. Consider JPG instead of PNG
4. Check file sizes are under limits
