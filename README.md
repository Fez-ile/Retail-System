# Retail-System (E-Commerce Web Application)

A full-stack retail/e-commerce web application built using PHP and MySQL. This system allows users to browse products, add items to a cart, and place orders, while also providing basic admin functionality for managing products and users.


Features

-User Registration & Login

-Shopping Cart Functionality

-Product Listing & Management

-Order Placement System

-Admin Role Support

-MySQL Database Integration

-Clean and modern UI design


Technologies Used

Frontend: HTML5, CSS3, JavaScript

Backend: PHP

Database: MySQL

Version Control: Git & GitHub

Local Server: XAMPP
